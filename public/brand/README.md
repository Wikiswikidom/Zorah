# Zorah brand assets

## Official logo placement

Put the final official Zorah logo in this folder.

Recommended primary asset:

`public/brand/zorah-logo.svg`

Optional raster fallback:

`public/brand/zorah-logo.png`

The site can reference the SVG as `/brand/zorah-logo.svg`.

### Asset guidance

- Prefer SVG for the logo because it stays sharp on mobile and desktop.
- Preserve the original black/gold artwork exactly; do not redraw or approximate it in code.
- Keep a transparent background unless the supplied brand artwork intentionally includes one.
- Do not crop or add filters to the official logo.
- If the logo contains a wordmark plus symbol, keep both together as the primary lockup unless the brand owner approves a separate symbol mark.

The current `/brand/zorah-wordmark.svg` is only a temporary fallback. Replace it with the supplied official asset when available.
