# Address Management

Customer addresses should include recipient name, phone, state, city, area, street address, landmark and delivery instructions as required by the business.

Customers may save multiple addresses and select a default. Sensitive data is accessible only to the owner and authorized operational staff.

Checkout should snapshot the selected delivery address into the order so later address edits do not change historical orders.

Validation should be practical for Nigerian addresses and should not assume international postal-code formats are always available.
