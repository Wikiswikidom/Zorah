# Security Testing

Test authentication/session handling, authorization bypass attempts, RLS policies, input validation, XSS, CSRF where applicable, injection, file uploads, rate limits, password reset, admin routes, webhook verification, payment manipulation and idempotency.

Use both automated checks and manual adversarial testing. Test each admin role separately.

Security findings should be classified by severity; critical/high issues block release until fixed or explicitly risk-accepted by the appropriate owner.
