# QA Checklist

- [ ] Landing page works on mobile/tablet/desktop.
- [ ] Navigation and search work.
- [ ] Filters/sorting work.
- [ ] Product variants and stock are correct.
- [ ] Wishlist/cart persist correctly.
- [ ] Checkout validates totals server-side.
- [ ] Paystack test success/failure/cancel flows pass.
- [ ] Orders and notifications are correct.
- [ ] Customer cannot access another customer's data.
- [ ] Admin roles cannot perform unauthorized actions.
- [ ] Custom orders and uploads work safely.
- [ ] SEO metadata/sitemap/structured data pass validation.
- [ ] Accessibility and performance checks pass.
- [ ] No console errors or leaked secrets.
