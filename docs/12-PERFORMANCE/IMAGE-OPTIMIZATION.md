# Image Optimization

Product imagery is a primary brand asset and performance risk. Store originals securely, then serve responsive optimized derivatives.

Use modern formats where supported, correct dimensions, meaningful filenames and descriptive alt text. Avoid shipping a desktop-size image to a small phone.

Lazy-load non-critical media; prioritize the hero/product primary image. Provide explicit dimensions/aspect ratios to reduce layout shift.

Uploads must validate file type, dimensions, size and content before becoming public assets.
