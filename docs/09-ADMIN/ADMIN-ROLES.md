# Admin Roles

Super Admin: full administrative access.

Catalog Admin: products, variants, media, categories, collections and inventory.

Order Admin: orders, payment status visibility, delivery and fulfilment.

Content Admin: homepage, editorial content, navigation and static content.

Marketing Admin: promotions, featured products and campaigns.

Support Admin: customer support data, enquiries and custom orders.

Analytics Admin: reporting and analytics.

Role capabilities are implemented through granular permissions, not route names alone.
