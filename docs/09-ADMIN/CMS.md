# CMS

The CMS controls editable business content while preserving the application design system.

Editable areas: hero heading/media/CTA, featured collections, promotional banners, announcement bar, selected homepage sections, testimonials, craftsmanship content, footer text/social links and SEO fields.

Do not expose arbitrary CSS or unrestricted theme values. Brand styling remains developer-controlled through design tokens and approved presets.

CMS content requires validation, draft/publish state, preview where useful and audit history for important changes.
