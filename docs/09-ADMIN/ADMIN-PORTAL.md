# Admin Portal

The admin portal is a protected application area with role-aware navigation and actions.

Core modules: dashboard, products, categories/collections, inventory, orders, payments, delivery, custom orders, customers, CMS, promotions, reviews, notifications, reports and audit logs.

The portal should prioritize operational clarity over decorative UI. Tables need search, filters, pagination, clear status badges and safe bulk actions.

Every privileged mutation requires server authorization and audit logging where appropriate.
