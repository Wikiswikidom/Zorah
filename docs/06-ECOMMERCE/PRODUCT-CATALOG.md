# Product Catalog

Product model should support name, slug, description, short description, materials, dimensions, care instructions, price, status, SEO metadata, categories, collections and media. Variants should support SKU, color, size where applicable, price override where approved, stock and media.

Product lifecycle: draft → review → published → archived. Archived products should preserve historical references.

Catalog admin must validate required fields before publishing. Slugs must be unique and stable where possible.

Product pages should expose rich media, availability, customization options where applicable, what-fits-inside information, shipping/returns and related products.
