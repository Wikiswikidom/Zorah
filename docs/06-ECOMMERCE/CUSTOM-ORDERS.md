# Custom Orders

Custom ordering is a first-class Zorah capability.

Request fields: bag style, material/leather, color, hardware, size, strap/handle preference, personalization, reference images and special instructions.

Workflow: submitted → under review → needs clarification → quoted → awaiting customer → approved → converted to order or declined → completed.

Admins can add internal notes, customer-facing updates, quote amount, proposed design and attachments. Customers can view status and respond through the approved communication channel.

Uploads require strict validation and private access controls.
