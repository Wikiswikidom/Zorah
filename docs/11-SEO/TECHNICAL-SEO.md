# Technical SEO

Use semantic HTML, stable clean URLs, metadata, canonical tags, sitemap.xml, robots.txt, Open Graph metadata, correct redirects and appropriate indexation rules.

Public product/category/collection pages should be crawlable. Admin, account, checkout and private tracking surfaces should generally not be indexed.

Avoid duplicate URLs caused by filter/query combinations. Use canonicalization and controlled crawl rules rather than blocking important product discovery paths.

Monitor crawl errors and index coverage after launch.
