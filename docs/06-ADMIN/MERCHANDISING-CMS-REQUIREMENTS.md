# Zorah Admin CMS — Merchandising & Advertising Requirements

## Purpose
Authorised staff must control merchandising content without raw HTML or accidental destruction of the Zorah design system.

## Promotional / advertising system
Admins can create, edit, schedule, publish, pause, expire and remove promotional content on both landing and shop surfaces.

Supported types: announcement strip, hero campaign, editorial banner, flash/limited-time sale, product promotion rail, news/editorial promotion and collection promotion.

Each campaign supports title, description, CTA, destination, media, start/end date and time, placement, status, optional countdown, priority/order, and optional product/collection association.

Statuses: Draft, Scheduled, Published, Paused, Expired.

## Landing-page CMS
Controlled sections: Hero, Campaign banners, Featured products, Collections, Craft/Story, Editorial/News, Custom Orders, Journal and Newsletter.

Admins can add, edit, reorder, publish/unpublish, schedule and remove sections.

## Merchandising safety
- Structured content fields only; no arbitrary HTML editor.
- Visual design tokens remain controlled by code.
- Campaign scheduling must respect start/end times automatically.
- Expired promotions stop displaying automatically.
- Admin actions should be auditable.

## Future roles
Owner, Admin, Editor, Merchandiser, Support/Operations and Read-only.

## Phase placement
This is a carried-forward requirement for Phase 2D and must remain compatible with Phase 2C product, cart, wishlist and merchandising contracts.
