# Technology Stack

**Web:** Next.js, React, TypeScript.

**Styling:** Tailwind CSS with a documented Zorah design system.

**Animation:** A lightweight, carefully selected library only where native CSS/Next.js behavior is insufficient.

**Backend/data:** Supabase PostgreSQL, Auth and Storage; Realtime only where it creates clear operational value.

**Payments:** Paystack.

**Hosting/CDN:** Vercel.

**Source control:** GitHub.

**Email:** transactional email provider to be finalized; Resend is a candidate.

**Monitoring:** Vercel monitoring with optional Sentry after production needs are established.

Dependencies must be justified by user value, security, maintenance cost and bundle impact.
