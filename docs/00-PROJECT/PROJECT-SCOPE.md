# Project Scope

## In scope
Landing page, shop, collections, search, filters, product pages, wishlist, cart, checkout, customer account, addresses, delivery, order tracking, custom orders, reviews, CMS, admin RBAC, inventory, Paystack, email/in-app notifications, SEO, analytics/monitoring, accessibility and testing.

## Out of scope for initial launch
Pickup stations, native mobile apps, marketplace integrations, complex multi-vendor selling, uncontrolled theme editing, and WhatsApp/SMS automation unless later approved.

## Architectural boundary
Next.js/TypeScript/React frontend and server capabilities; Supabase PostgreSQL/Auth/Storage; Vercel hosting; Paystack payments; transactional email provider to be selected before integration.

## Scope control
New requirements enter `OPEN-QUESTIONS.md` or the decision log before implementation. Security, payment and data-model changes require explicit review.
