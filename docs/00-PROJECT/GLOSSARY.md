# Glossary

**SKU** — Stock keeping unit for a sellable product/variant.

**Variant** — A purchasable variation such as color or size.

**RLS** — PostgreSQL row-level security controlling which rows a database role may access.

**RBAC** — Role-based access control for application permissions.

**CMS** — Content management system used by authorized admins.

**Custom order** — Customer request for a customized handbag requiring review/quotation.

**Idempotency** — Guarantee that repeating an operation does not create duplicate business effects.

**Webhook** — Server-to-server event notification from a provider such as Paystack.

**Core Web Vitals** — User-centric web performance metrics used for loading, interactivity and visual stability.

**Canonical URL** — Preferred URL for indexing when equivalent pages exist.
