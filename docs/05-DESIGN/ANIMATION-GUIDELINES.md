# Animation Guidelines

Animation should feel slow, precise and intentional. Preferred uses: image reveal, subtle page transitions, editorial scroll storytelling, hover elevation and cart feedback.

Avoid continuous motion, bouncing UI, excessive parallax and animations that delay interaction.

Respect `prefers-reduced-motion`. Every animation must have a useful static state and should not block navigation or checkout.

Performance rule: animate opacity/transform where possible and avoid large layout-triggering animations. Product imagery remains the visual hero.
