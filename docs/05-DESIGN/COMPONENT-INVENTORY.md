# Component Inventory

Core components: Header, announcement bar, footer, hero, editorial section, collection card, product card, product gallery, price block, variant selector, filter drawer, sort control, search interface, breadcrumb, wishlist button, cart drawer, quantity control, address form, checkout summary, payment state, order timeline, custom-order configurator, review list, notification center, modal, toast, tabs, accordion and admin data table.

Components must have documented states: loading, empty, error, disabled, success and mobile behavior where relevant.

Business-critical components require accessibility and automated tests.
